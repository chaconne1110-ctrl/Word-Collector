checklist1. 고른 단어

    단어 칸을 눌러 직접 고칠 수 있어요. (예: plasmonic → plasmonic effect) 단어마다 파일에서 나온 원문 문장을 참고 문장으로 넣어 하나씩 분석하고, 검토한 뒤 저장해요. 단어마다 분석 1회가 쓰여요. (하루 한도: 기기당 200회)

    category2. 의미 기준

    일상에서 널리 쓰이는 일반적인 뜻으로 분석합니다. (예: current → 흐름, 현재의)

    입력한 전공에서 쓰이는 뜻으로 분석합니다. (예: current + 전기공학 → 전류)

    전공을 모를 때 사용합니다. 참고 문장에서 단어가 쓰인 뜻을 보고, 가장 관련 있는 전공을 찾아 분석합니다. 아래 참고자료에 문장을 꼭 입력해 주세요.
