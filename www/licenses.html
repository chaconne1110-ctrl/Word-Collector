오픈소스 라이선스

"PDF·사진에서 단어 찾기"는 아래 오픈소스 부품을 앱 안에 넣어, 파일을 서버로 보내지 않고 이 기기에서 글자를 읽습니다. 각 부품의 저작권은 표시된 저작자에게 있으며, 라이선스 전문은 앱에 함께 들어 있습니다.

PDF·사진 글자 읽기

  • PDF.js (pdfjs-dist 6.5.438, legacy 빌드)

    용도: PDF의 글자 층 읽기, 스캔한 쪽을 그림으로 그리기

    저작자: Mozilla Foundation · 라이선스: Apache License 2.0 (전문)

    출처: github.com/mozilla/pdf.js

  • Tesseract.js 7.0.0

    용도: 사진과 스캔한 PDF 쪽의 영어 글자 인식 (WebAssembly)

    저작자: Project Naptha 외 · 라이선스: Apache License 2.0 (전문)

    출처: github.com/naptha/tesseract.js

  • tesseract.js-core 7.0.0 (Tesseract OCR 엔진)

    용도: 글자 인식 엔진 (LSTM 전용 빌드 2종: SIMD, 일반)

    저작자: Tesseract OCR 프로젝트, Project Naptha 외 · 라이선스: Apache License 2.0 (전문)

    출처: github.com/naptha/tesseract.js-core, github.com/tesseract-ocr/tesseract

  • 영어 인식 데이터 eng.traineddata (tessdata_best, 정수형)

    용도: 영어 글자 인식 학습 데이터 (@tesseract.js-data/eng 1.0.0 패키지의 4.0.0_best_int)

    저작자: Tesseract OCR 프로젝트 · 라이선스: Apache License 2.0 (전문)

    출처: github.com/tesseract-ocr/tessdata_best
