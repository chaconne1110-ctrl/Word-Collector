## 발견 및 수정

1. 긴 표제어가 있는 분석 대기창이 낮은 가로 화면에서 안전 여백을 침범했다. 대기창 내부 높이를 제한하고 스크롤을 허용했다. 네이티브 모달로 바꿔 키보드 포커스가 뒤쪽 메뉴로 빠지지 않게 했다. 취소/Escape는 입력 화면으로 돌아가 입력값을 보존한다.
2. 가로 화면에서 번역 입력칸 아래쪽이 저장 영역에 일부 가려졌다. 진행 상태 문구를 본문으로 옮기고 낮은 화면의 헤더·저장 영역 여백을 줄였다. 입력 포커스와 화면 크기 변경 시 해당 입력칸을 본문 가운데로 스크롤한다.
3. 분석 중 페이지를 떠났다가 브라우저 복귀 캐시로 돌아오는 경우 대기 상태가 남을 수 있었다. 떠날 때 타이머와 대기창을 종료하고, 복귀 시 명시적인 재시도를 안내한다. 재진입한 분석 함수도 실행 중에는 추가 요청하지 않는다.
4. 입력 화면에 남아 있던 “분석과 사진 생성 후 검수” 안내를 현재 동작에 맞게 수정했다. 사진은 현재 v1과 동일하게 플래시카드에서 별도로 요청한다.
5. 기존 브라우저 검사가 제거된 앞면/뒷면 버튼 및 단일 화면 분석 흐름을 참조했다. 카드 본문 탭과 별도 분석 페이지 흐름으로 갱신했다. 모바일 화면 배율이 적용된 경우 물리 화면 폭과 CSS 뷰포트 폭을 구분하도록 검사를 수정했다.

## 현재 동작 및 확인 범위

- 현재 v1은 테스터 코드 입력 대신 기기 식별 방식이다. 인증 입력 UI를 다시 추가하지 않았다.

- 실제 Android APK/iOS 기기, 운영 AI 서버 응답·요금/쿼터·배포 완료 여부는 이 로컬 점검으로 확인하지 않았다.
- 저장소의 버전 브랜치 배포 설정상 `v1.1` push는 GitHub Pages 배포 워크플로도 실행한다. 코드 저장 성공과 웹 배포 성공은 별개다.
