# Word Collector 웹 테스트 버전

AI API 없이 단어 입력·수정과 CSV/XLSX 내보내기를 시험하는 독립 웹 버전입니다. 현재 배포된 시험용 페이지의 정적 소스를 그대로 포함했습니다.

## Windows에서 실행

이 브랜치를 내려받아 압축을 푼 후, 저장소 폴더에서 PowerShell을 열고 다음을 실행하세요. Node.js 22 이상을 권장합니다. npm 설치, Android Studio, Gemini 키는 필요하지 않습니다.

```powershell
node .\web-test\server.cjs
```

브라우저에서 **http://127.0.0.1:8080** 을 엽니다. 실행한 PowerShell은 켜 둡니다. 종료는 Ctrl+C입니다. 이미 8080 포트를 쓰고 있다면:

```powershell
$env:PORT = '8081'
node .\web-test\server.cjs
```

이때는 http://127.0.0.1:8081 을 엽니다. 서버는 PC 내부에서만 접속할 수 있도록 설정했습니다. 실행 위치가 web-test 폴더라면 `node server.cjs`로 실행할 수 있습니다.

## 시험 순서

1. **예시 채우기**를 누릅니다.
2. 뜻·정의·예문 등을 수정하고 **테스트 단어 저장**을 누릅니다.
3. 전체/단어장을 선택합니다.
4. **CSV로 저장**, **XLSX로 저장**을 각각 눌러 내려받습니다.
5. Excel 또는 스프레드시트에서 한글·7열·예문이 유지되는지 확인합니다.
6. 편집 대상에서 저장한 단어를 선택해 수정하고 다시 내보내 최신 값이 반영되는지 확인합니다.

출력은 전공, 단어장 이름, 표제어, 한글 뜻, 영어 정의, 정의 한글해석, 예문(영어)의 7열입니다. 없는 항목은 빈 칸이며 예문 번역·품사·최초 입력 원문은 출력하지 않습니다. 예시는 고정된 테스트 자료이며 AI 호출 결과를 새로 생성하지 않습니다.

## 데이터와 배포

- 데이터는 브라우저 localStorage에 저장됩니다. 이 서버는 단어를 받거나 보관하지 않고 정적 파일만 제공합니다.
- 브라우저·주소·포트가 달라지면 저장 공간도 다릅니다. 휴대폰 앱의 데이터가 자동으로 나타나지 않습니다.
- `테스트 자료 초기화`는 이 웹 페이지에서 저장한 데이터를 기본 예시로 되돌립니다.
- 모든 실행 자산은 `public/` 안에 있으며 외부 CDN이나 API에 의존하지 않습니다.
- `public/` 폴더를 정적 호스팅 서비스에 올려도 실행할 수 있습니다. 이 PR은 GitHub Pages 설정이나 배포를 변경하지 않습니다.
- 기존 비공개 시험 주소: https://wordcollector-csv-xlsx-lab-20261108.chaconne1110.chatgpt.site (소유자 계정 로그인 필요 가능)
- Sites 프로젝트 식별자, 배포 인증 정보, `.env`, 개인 저장 데이터는 이 폴더에 포함하지 않았습니다.

## 검사

저장소 루트에서 실행합니다.

```powershell
node --test web-test/tests/demo.test.cjs web-test/tests/server.test.cjs
```

단어 생성·수정·검증 로직 3개와 실제 HTTP 서버 검사 1개를 통과했습니다. CSV/XLSX 엔진은 기존 검증된 내보내기 구현과 동일합니다. 새 웹 화면 전체의 자동 브라우저 검증은 도구 제약으로 완료하지 못했습니다.

## 소스 구성

- `server.cjs`: 추가 의존성 없는 로컬 정적 서버
- `public/index.html`: 입력·수정·내보내기 시험 화면
- `public/demo-data.js`, `demo-editor.js`: 시험용 데이터 처리와 입력 UI
- `public/word-export.js`, `csv-export.js`: 실제 CSV/XLSX 생성 및 웹 저장
- `public/data.js`: 앱의 기본 예시
- `public/export.html`: 내보내기 전용 화면

실서비스 내보내기 엔진과 테스트용 복사본을 수정할 때는 양쪽 반영 여부를 확인하세요. 이 버전은 API 연동·Android 네이티브 파일 저장을 시험하는 용도가 아닙니다.
